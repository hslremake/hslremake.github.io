HSLR MOD Guide

The MOD editor ships with the game. Character skins, fonts, music, voice lines, translations and equipment — all six live in the same screen. No coding, no config files to hand-edit.

Six kinds of MOD

Each chapter stands alone; read them in any order. If this is your first MOD, start with Skins.

Sample packs

Finished official MODs. Unzipping one and reading it alongside the guide is the fastest way in.

These zips are teaching material for people who want to build MODs — they are not installers. If you just want to play with MODs, subscribe on the Steam Workshop and the game installs them for you. To install one by hand:
  1. Unzip it — you get a single MOD folder
  2. Move that whole folder into %USERPROFILE%\AppData\LocalLow\UserJoy\HSLR\Mods\
  3. Back in the game, open MOD Manager, tick it, then press Apply Changes
