Before you start

Finding the MOD screen

Launch the game, and on the title screen clickWorkshop in the bottom-left corner。

Three buttons

That takes you to the Mod Manager, where each of the three buttons does one job:

Use other people's
Manage Mods

Manage the MODs you have installed (local and Workshop):enable, disable and reorder them. When you have finished building a MOD, this is also where you press Apply Changes to see it in action.

Build your own

Create and edit MOD content.Everything in this guide happens on this one screen — Asset Library, Appearance, Fonts, Music & SFX, Voice, Localization and Edit Equipment are all here.

Three things to know first

Get these three straight before you start and you will save yourself a lot of backtracking.

FirstTarget package — which MOD you are editing

Every page except Tutorial and Asset Library has aTarget package: selector in the top-right corner. It shows what you are currently editing; everything you save is written into that package. Open it and there is an input field at the bottom —type a new name, press Create, and you have started a new MOD package。

SecondThe page toggle — whether this package covers this kind of content

Every content page has atoggle in the top-left corner (showing Enabled or Disabled). A new package starts with all of them off, so turn on whichever one you are working on. A page that is off has no effect when applied, even if you have set things up on it.

The small dot next to each item in the left-hand list is that page's status:filled = Enabled, hollow = Disabled, so you can see at a glance what a package covers. Toggling one is written to disk by Save Settings in the top-right corner; it does not take effect on its own.

ThirdSaving is not applying

These two are easy to confuse and completely different:

  • Save Settings — writes your edits into the MOD package on disk. Every page has this in the top-right corner.
  • Apply Changes — go to Manage Mods, tick the package and press it; the game reloads on the spot, so youdo not need to restart。

You get a warning if you leave a page, switch target package or close the window with unsaved work. Nine times out of ten, "I saved it but nothing happened" means Apply Changes was never pressed.

02

Asset Library: where your files go

Every file you want to use — fonts, music, voice clips, icons — goes into theAsset Library first. It is one foldershared by every MOD package, stored under the game's save directory.

When you pick an asset on an editing page and pressSave Settings, only the files youactually usedare copied into your MOD package. That is why a published package is always self-contained — nobody downloads it and finds files missing.

You do not need to memorise the path Every tab on the Asset Library page has anOpen folderbutton in the top-right corner that opens Explorer straight at the right place.

If you want to find it yourself, it lives here:

Asset Library locationPaste it into Run (Win + R) and press Enter
%USERPROFILE%\AppData\LocalLow\UserJoy\HSLR\ModAssetLibrary\

Inside are seven folders by type, matching the seven tabs across the top of the Asset Library page:

Remember to press Rescan after copying files in The list does not refresh by itself. If a file you just copied in is missing, press Rescan in the tab's top-right corner and it will show up.
03

Changing the font

A font MOD replacesall text in the game UIwith the font file you choose. You do not need to — and cannot — say which of the game's typefaces to swap: pick one font and everything changes.

Step 1Put the font into the Asset Library

Go toAsset Library, switch to theFontstab, pressOpen folder, and drop your .ttf or .otf file in.

Step 2Tick one on the Fonts page

In the left-hand list clickFonts, check that theTarget packageat the top is the package you mean to edit, turn on thePage togglein the top-left corner, then tick the font you want in the list.

One MOD, one font Ticking a new one unticks the old one automatically. To offer players a choice, ship several MOD packages.

TheStatuscolumn on the right of each row shows a greenLibrary · ready, meaning the font is in the Asset Library and ready to use. If a file you just dropped in is not listed, pressRescan」。

Step 3Save Settings

PressSave Settingsin the top-right corner. The font file iscopied into the package's font\folder, so the package is self-contained — zip it and it is ready to share.

Thenapply it in Manage Modsand it takes effect. Untick it and apply again to go back to the game's default font.

Missing characters fall back to the original font Chinese fonts rarely include Korean Hangul. When a character is missing, the game draws it in the original font, so it never turns into a blank box. Seeing the two mixed on screen — Han characters in your font, Hangul unchanged — is expected.

Apply and publish

Seeing it in game

  1. On the editing page, pressSave Settings」／「Save (top-right corner of every page)
  2. Use< Backin the top-left corner to return to the Mod Manager, then openManage Mods」
  3. Find your package in the Installed MODs list and tickLoaded
  4. Press the redApply Changesbutton in the top-right corner — the game reloads on the spot, so youdo not need to restart
  5. Go back into the game and your work is there
Saved, but nothing changed? Nine times out of ten, Apply Changes was never pressed. Also check that thetop-left page toggleon the page you edited is on, and that the package isticked。

Publishing to the Workshop

The Create Mod page has a redbottom-left cornerbutton in thePublish to Workshop. Publishing runs Save all first, andwhat goes out cannot be taken back, so you get a confirmation dialog. The cover image comes from the package's preview.png。

Finished MODs are yours to upload and share — other players can then subscribe to your work straight from the Workshop.
